Work Handoff · 작업 인계서 만들기

AI 에이전트 작업 기록을 넣고, AI 초안을 만든 뒤, 사람이 원문과 대조해 검토한 인계서(Markdown)로 내려받습니다. 입력 내용은 저장하지 않습니다(새로고침하면 사라질 수 있습니다).

1. 작업 기록 넣기

에이전트 대화 기록, 작업 메모, 로그 등 1–3개(합계 20,000자 이하). 기록마다 doc1, doc2, doc3 번호가 붙습니다. 파일은 이 브라우저 안에서 읽으며, 한도를 넘으면 자르지 않고 알려 줍니다.

텍스트 파일을 여기에 끌어다 놓으세요

원본 기록 후보

인수인계할 내용의 원본(에이전트 대화 기록·작업 메모·로그)이 있는 폴더 안의 텍스트 기록 후보입니다. 체크한 파일만 이 페이지의 기록으로 읽어 옵니다. 이 위치는 앱의 저장 위치나 인계서를 내려받는 곳이 아니며, 앱은 이 폴더에 아무것도 쓰지 않고 기억하지도 않습니다. 브라우저 보안상 전체 경로는 알 수 없어 고른 폴더 이름과 그 안의 상대 경로만 보여 줍니다. 원본 파일 하나만 넣으려면 [파일 고르기]를 쓰세요.

    2. AI 초안 만들기

    두 방법 중 하나를 고르세요. 어느 쪽이든 같은 검증·검토·내보내기를 거칩니다. 앱은 인용문이 원문에 글자 그대로 있는지만 확인하고, 내용이 사실인지는 판단하지 않습니다. 결과는 초안일 뿐이며 자동으로 확인되지 않습니다.

    이 버튼을 누를 때만 위 기록 원문과 작성 지시문이 이 컴퓨터에 로그인된 Claude CLI를 거쳐 Anthropic의 Claude로 전송됩니다. 누르기 전에는 아무것도 보내지 않습니다. API 키·새 구독·결제는 쓰지 않습니다.

    이 앱은 다른 AI와 연결되지 않고 아무것도 보내지 않습니다. 프롬프트를 만들어 주면 직접 복사해 이미 쓰고 있는 AI 대화창(예: ChatGPT, Gemini, Codex, Claude 웹)에 붙여넣고, 받은 JSON 답변을 다시 이 페이지에 붙여넣어 검증합니다.

    다른 AI에서 초안 만들기(수동): 프롬프트를 복사해 원하는 AI 대화창에 붙여넣고 JSON 답변 받기

    프롬프트 만들기·복사

    이 앱은 이 프롬프트를 보내지 않습니다. 복사해서 이미 쓰고 있는 AI 에이전트 대화창(예: Claude, ChatGPT, Codex 세션)에 직접 붙여넣으세요. 프롬프트에는 기록 원문이 들어 있으니 그 대화창에 보내도 되는 내용인지 먼저 확인하세요. 본문은 형식을 정확히 지키도록 영어로 되어 있습니다.

    JSON 초안 붙여넣기·검증

    AI 초안 버튼으로 받은 답변도 여기에 들어갑니다. {로 시작해 }로 끝나는 JSON을 붙여넣으세요. 답변 전체가 ```json 코드 블록 하나로 감싸져 있으면 검증할 때 그 표시만 지웁니다.

    자세한 사용 안내
    1. 앱 작업 기록 파일을 끌어다 놓거나 고르거나, 직접 붙여넣기로 붙여넣습니다. 처음이라면 예시로 체험하기를 눌러 보세요.
    2. 앱 Claude CLI로 바로 초안 만들기를 누르면 기록이 Claude로 전송되고, 돌아온 JSON 초안을 앱이 바로 검증합니다. 이 기능은 python3 web/server.py로 실행했을 때만 동작합니다.
    3. 직접 기록을 Claude로 보내고 싶지 않거나 AI 초안이 실패하면, 다른 AI에서 초안 만들기를 눌러 프롬프트를 복사해 원하는 AI 대화창에 붙여넣고 받은 JSON을 붙여넣어 검증합니다.
    4. 앱 앱은 인용문이 원문에 글자 그대로 있는지만 확인합니다. 인용이 있다고 내용이 사실이라는 뜻은 아닙니다.
    5. 직접 각 항목을 원문과 대조해 고치고 확인함 또는 검토 필요로 표시한 뒤 Markdown을 내려받습니다. 모든 항목은 검토 필요로 시작합니다.

    3. 사람이 검토하기

    앱은 각 인용문이 원문에 글자 그대로 있는지만 확인합니다. 내용이 사실인지, 인용이 주장을 뒷받침하는지, 기록끼리 충돌하는지는 판단하지 않습니다. 그 판단은 검토하는 사람이 합니다.

    AI 초안을 만들거나 JSON 초안을 검증하면 여기에 검토할 항목이 나타납니다.
